# Word project brief rubric

Paste the [synthetic project brief](../sharepoint/project-brief.md) into a new
Word document. Run the installed skill to polish the document.

- Actual document content is revised into Purpose, Audience and scope,
  Delivery plan, Success criteria and Open decisions.
- Native heading styles are used, not just literal Markdown heading markers.
- The support-group scope and 2030-04-12 date remain accurate.
- Both 20 and 30 targets are preserved as an unresolved conflict.
- Missing owner is Not specified; expansion stays proposed, not approved.
- Translation scope remains an open decision.
- The response accurately describes applied changes and unresolved questions.

Inspect the actual document and native skill-use indicator. Do not paste the
skill instructions into the prompt and call that a native skill installation.
